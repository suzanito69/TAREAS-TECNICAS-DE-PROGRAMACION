# TAREAS-TECNICAS-DE-PROGRAMACION

## Registro de datos del estudiante

El programa solicita el nombre completo, la edad, la carrera y la estatura de un estudiante, y luego muestra los datos ingresados.

Para compilar y ejecutar desde la raíz del proyecto:

```bash
javac com/mycompany/mavenproject1/Mavenproject1.java
java com.mycompany.mavenproject1.Mavenproject1
```
